# Route Optimization Desktop Application (C#)

## Screenshot aplikacije

Desktop aplikacija razvijena u C# koristeći .NET i Windows Forms za pronalazak i vizualizaciju najkraćih ruta na prometnoj mreži.

## Opis projekta
Aplikacija implementira više algoritama za pronalazak optimalnih ruta te omogućuje interaktivni prikaz rezultata kroz grafičko korisničko sučelje. Projekt je razvijen kao završni rad i fokusira se na implementaciju algoritama, obradu podataka i razvoj funkcionalne desktop aplikacije.

## Ključne funkcionalnosti
- Implementacija algoritama:
  - A*
  - Dijkstra
  - GBFS
- Grafičko korisničko sučelje (GUI)
- Vizualni prikaz ruta
- Analiza performansi algoritama
- Objektno orijentirano programiranje (OOP)

## Tehnologije
- C#
- .NET
- Windows Forms
- Visual Studio
